☁️ Cloud setup — Firebase Rules (1 choti matra)

Firebase Console → Firestore Database → Rules ma tala ko rule thapnus, natra cloud save hudaina (local ma matra baschha):

match /ledgers/{uid} {
  allow read, write: if request.auth != null
    && request.auth.uid == uid;
}

Rules thapepachhi page reload garnus.
