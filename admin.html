    ड्यासबोर्डDashboard

    माथि Today, 7 days वा This month छान्नुहोस्। कार्डहरूले त्यो अवधिको Revenue (आम्दानी), Gross profit (कुल नाफा), बिक्री भएका डायमन्ड र Transactions (कारोबार संख्या) देखाउँछन्, साथै अघिल्लो अवधिसँगको तुलना (↑/↓ %)। “Pending delivery” मा डायमन्ड पठाउन बाँकी अर्डर र “Accounts receivable” मा ग्राहकबाट उठाउन बाँकी रकम देखिन्छ। Quick sell थिचेर एकै पटकमा बिक्री सुरु गर्न सकिन्छ। दिनको अन्त्यमा “Share day report” थिचेर आजको हिसाब WhatsApp मा पठाउन सकिन्छ।

    Choose Today, 7 days or This month at the top. The cards show revenue, gross profit, diamonds sold and number of transactions for that period, compared with the previous period (↑/↓ %). “Pending delivery” lists orders not yet delivered and “Accounts receivable” lists amounts customers still owe. Use Quick sell to start a sale in one tap, and “Share day report” at the end of the day to send today’s summary on WhatsApp.

    ग्राहक अर्डरOrders

    Share order page थिचेर लिंक ग्राहकलाई पठाउनुहोस्। ग्राहकले प्याकेज, UID र नाम हालेर अर्डर पठाउँछन्; यहाँ “New” मा आउँछ र Dashboard मा सूचना देखिन्छ। Accept & record sale थिच्दा सबै विवरण भरिएर बिक्री खुल्छ, Save गरेपछि अर्डर “Accepted” मा जान्छ। पहिलो पटक: Firebase → Authentication → Sign-in method मा Anonymous र Google दुवै Enable गर्नुहोस्, तलको Firestore Rules paste गरेर Publish गर्नुहोस्, अनि ग्राहकको अर्डर पेज (index.html) र यो admin.html दुवै GitHub repo मा राख्नुहोस्। ग्राहकले आफ्नो Customer ID, अर्डर इतिहास र स्थिति “My account” मा हेर्न सक्छन्। नयाँ अर्डर आउँदा घण्टी बज्छ (Alert settings बाट बन्द/खोल्न मिल्छ)। “Taking orders” स्विचले अर्डर पेज तुरुन्त बन्द वा खोल्छ। १५ मिनेटभन्दा बढी पर्खिरहेका अर्डर रातो देखिन्छन्, र “paid” भनेका अर्डर सबैभन्दा माथि आउँछन्। ग्राहकले “I’ve paid” थिच्दा पेमेन्टको स्क्रिनसट पनि पठाउन सक्छन्, 🖼 Screenshot थिचेर हेर्नुहोस्। यसका लागि तलका rules फेरि कपी गरेर Firebase → Firestore → Rules मा Publish गर्नुहोस्।

    Tap Share order page and send the link to customers. They choose packages, enter their UID and name, and the order arrives here under “New” with an alert on the dashboard. Accept & record sale opens a filled-in sale; after saving, the order moves to “Accepted”. First time only: in Firebase → Authentication → Sign-in method enable both Anonymous and Google, paste these Firestore rules and publish, and keep index.html (the customer order page) next to admin.html in your GitHub repo. Customers see their Customer ID, order history and status under “My account”. A chime plays when a new order arrives (turn it off under Alert settings). The “Taking orders” switch pauses or reopens your order page at once. Orders waiting more than 15 minutes turn red, and orders the customer marked as paid come first. Customers can attach a payment screenshot when they tap “I’ve paid”; open it with the 🖼 Screenshot button. For screenshots to work, copy the rules below again and publish them in Firebase → Firestore → Rules.

    rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    function isAdmin() {
      return request.auth != null && request.auth.token.email == 'yonghangissac@gmail.com';
    }
    match /users/{uid}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
    match /public/{doc} {
      allow read: if true;
      allow write: if isAdmin();
    }
    match /customers/{cid} {
      allow read: if request.auth != null && (request.auth.uid == cid || isAdmin());
      allow create, update: if request.auth != null && request.auth.uid == cid
        && request.resource.data.keys().hasOnly(['code','name','phone','ffUids','createdAt','updatedAt','email'])
        && request.resource.data.code is string && request.resource.data.code.size() <= 10
        && request.resource.data.name is string && request.resource.data.name.size() <= 60
        && request.resource.data.phone is string && request.resource.data.phone.size() <= 15
        && request.resource.data.ffUids is list && request.resource.data.ffUids.size() <= 5;
      allow delete: if isAdmin();
    }
    match /orders/{id} {
      allow create: if request.auth != null
        && request.resource.data.cid == request.auth.uid
        && request.resource.data.keys().hasOnly(['name','phone','uid','items','method','note','at','status','total','cid','ccode','coupon','disc','ref'])
        && (!('disc' in request.resource.data) || (request.resource.data.disc is number && request.resource.data.disc >= 0))
        && (!('coupon' in request.resource.data) || (request.resource.data.coupon is string && request.resource.data.coupon.size() <= 16))
        && (!('ref' in request.resource.data) || (request.resource.data.ref is string && request.resource.data.ref.size() <= 12))
        && request.resource.data.status == 'new'
        && request.resource.data.name is string && request.resource.data.name.size() > 0 && request.resource.data.name.size() <= 60
        && request.resource.data.uid is string && request.resource.data.uid.size() <= 14
        && request.resource.data.phone is string && request.resource.data.phone.size() <= 15
        && request.resource.data.note is string && request.resource.data.note.size() <= 200
        && request.resource.data.items is list && request.resource.data.items.size() > 0 && request.resource.data.items.size() <= 12
        && request.resource.data.total is number && request.resource.data.total >= 0
        && request.resource.data.at is number;
      allow get: if isAdmin() || (request.auth != null && resource.data.cid == request.auth.uid);
      allow list: if isAdmin() || (request.auth != null && resource.data.cid == request.auth.uid);
      allow update: if isAdmin()
        || (request.auth != null && resource.data.cid == request.auth.uid && resource.data.status == 'new'
            && request.resource.data.diff(resource.data).affectedKeys().hasOnly(['paidAt','paidRef','paidShot'])
            && request.resource.data.paidRef is string && request.resource.data.paidRef.size() <= 40
            && (!('paidShot' in request.resource.data) || request.resource.data.paidShot is bool))
        || (request.auth != null && resource.data.cid == request.auth.uid && resource.data.status == 'new'
            && request.resource.data.diff(resource.data).affectedKeys().hasOnly(['status','cancelledAt'])
            && request.resource.data.status == 'cancelled');
      allow delete: if isAdmin();
    }
    match /payshots/{id} {
      allow read, delete: if isAdmin();
      allow create, update: if request.auth != null
        && get(/databases/$(database)/documents/orders/$(id)).data.cid == request.auth.uid
        && get(/databases/$(database)/documents/orders/$(id)).data.status == 'new'
        && request.resource.data.keys().hasOnly(['img','at'])
        && request.resource.data.img is string && request.resource.data.img.size() < 700000
        && request.resource.data.img.matches('data:image/(png|jpeg|webp);base64,.*');
    }
    match /dshots/{id} {
      allow write: if isAdmin();
      allow read: if isAdmin() || (request.auth != null && get(/databases/$(database)/documents/orders/$(id)).data.cid == request.auth.uid);
    }
    match /reviews/{id} {
      allow read: if isAdmin() || (request.auth != null && (resource == null || resource.data.cid == request.auth.uid));
      allow list: if isAdmin();
      allow create: if request.auth != null
        && request.resource.data.cid == request.auth.uid
        && get(/databases/$(database)/documents/orders/$(id)).data.cid == request.auth.uid
        && get(/databases/$(database)/documents/orders/$(id)).data.delivered == true
        && request.resource.data.keys().hasOnly(['stars','text','name','at','cid'])
        && request.resource.data.stars is int && request.resource.data.stars >= 1 && request.resource.data.stars <= 5
        && request.resource.data.text is string && request.resource.data.text.size() <= 160
        && request.resource.data.name is string && request.resource.data.name.size() <= 30;
      allow update, delete: if isAdmin();
    }
  }

    नयाँ बिक्रीNew sale

    प्याकेज छान्नुहोस्, ग्राहकको नाम, फोन र Free Fire UID लेख्नुहोस्। छुट दिनुभयो भने Discount (Rs) मा लेख्नुहोस्; Net price आफैं घट्छ। Amount received मा अहिले हातमा आएको रकम लेख्नुहोस्। USD from card ले यो बिक्रीमा कार्डबाट कति डलर जान्छ र बाँकी कति रहन्छ देखाउँछ। पूरा पैसा नआएको भए Payment method मा “Credit” (उधारो) छान्नुहोस्; बाँकी रकम Outstanding मा देखिन्छ। डायमन्ड पछि पठाउने भए Delivery status मा “Pending” छान्नुहोस्। अनि Save sale थिच्नुहोस्। डलर कार्डमा पुग्ने डलर छैन भने बिक्री सेभ हुँदैन, पहिले Load card गर्नुहोस्।

    Pick a package and enter the customer’s name, phone and Free Fire UID. If you give a discount, enter it in Discount (Rs); the net price updates. Enter the amount actually received. USD from card shows how many dollars this sale uses and the balance left. If the customer has not paid in full, set the payment method to “Credit”; the balance shows as Outstanding. If you will deliver later, set Delivery status to “Pending”. Then tap Save sale. If the dollar card doesn’t have enough dollars, the sale won’t save: load the card first.

    बिक्री खाताSales ledger

    सबै कारोबार मितिअनुसार मिलाइएका छन् र हरेक दिनको Revenue र Gross profit (GP) देखिन्छ। नाम, फोन वा UID ले खोज्नुहोस्। “Undelivered” मा पठाउन बाँकी र “Credit” मा उधारो बिक्री छुट्टै हेर्न सकिन्छ। ⋮ थिचेर Edit, Mark as delivered, Record payment, Send receipt वा Delete गर्नुहोस्।

    Every transaction is grouped by date with daily revenue and gross profit (GP). Search by name, phone or UID. Use the “Undelivered” and “Credit” filters to see orders not yet sent and sales on credit. Tap ⋮ to edit, mark as delivered, record a payment, send a receipt or delete. Deleting a sale that came from an online order also removes that order from the customer’s “My orders”.

    डलर कार्डDollar card

    सुरुमा Set opening balance थिचेर अहिले कार्डमा कति डलर छ र ती डलरको जम्मा रुपैयाँ मूल्य कति हो लेख्नुहोस्; त्योभन्दा अघिको हिसाब गनिँदैन। त्यसपछि हरेक पटक कार्ड लोड गर्दा Load card थिच्नुहोस्: कति USD आयो, कति NPR तिर्नुभयो र बैंक/सेवा शुल्क कति लाग्यो लेख्नुहोस्। एप्लिकेसनले Weighted average cost (WAC) अर्थात् प्रति डलर औसत लागत निकाल्छ। हरेक बिक्रीमा कार्डबाट USD घट्छ र त्यही औसत लागत COGS बन्छ, त्यसैले नाफा वास्तविक (actual) हुन्छ। कार्ड शुल्क, इन्टरनेट, यातायात जस्ता खर्च Add expense मा राख्नुहोस्; यी Reports मा Net profit बाट घट्छन्। महिनामा एक पटक कार्ड एपको बाँकी ब्यालेन्स Reconcile मा हालेर Book balance मिलाउनुहोस्। Card account summary मा महिनाअनुसार Opening balance + Loads − Used in sales − Fees = Closing balance (USD र NPR दुवैमा) देखिन्छ।

    First tap Set opening balance and enter the dollars on your card right now and their total value in rupees; nothing before that date is counted. Then tap Load card every time you top up your dollar card: enter USD received, NPR paid and any bank/service charges. The app keeps a weighted average cost (WAC) per dollar. Each sale draws USD from the card at that average, which becomes COGS, so profit is actual rather than estimated. Record card fees, internet, transport and other costs with Add expense; they are taken off net profit in Reports. Once a month, enter the real balance from your card app in Reconcile to keep the book balance correct. The card account summary shows, for each month, opening balance + loads − used in sales − fees = closing balance, in both USD and NPR.

    ग्राहकCustomers

    बिक्रीबाट आफैं बनेको ग्राहक खाता: पहिले फोन, त्यसपछि UID, त्यसपछि नामबाट मिलाइन्छ। हरेक ग्राहकको जम्मा Revenue, Gross profit र डायमन्ड देखिन्छ। ग्राहक थिच्दा उसको पूरा विवरण खुल्छ: जम्मा खर्च, नाफा, उठाउन बाँकी र किनेको इतिहास; त्यहीँबाट Sell again, WhatsApp वा Call गर्न सकिन्छ।

    Customer accounts are built from your sales, matched by phone, then UID, then name. Each shows lifetime revenue, gross profit and diamonds. Tap a customer to open their profile: total spent, profit, amount to collect and purchase history, with Sell again, WhatsApp and Call buttons.

    मूल्य सूचीPrice list

    हरेक प्याकेजको COGS (लागत), Selling price (बिक्री मूल्य) र Profit per unit (प्रति एकाइ नाफा) आजको डलर रेटमा देखिन्छ। Garena ले मूल्य बदलेमा Packages मा प्याकेज थिच्नुहोस्, Game price ($) बदल्नुहोस् र Save package थिच्नुहोस्। पुराना कारोबारको हिसाब बदलिँदैन।

    Shows COGS, selling price and profit per unit for every package at today’s exchange rate. When Garena changes a price, tap the package under Packages, update the game price ($) and tap Save package. Past transactions keep their original figures.

    मूल्य कसरी बन्छPricing

    बिक्री मूल्य आफैं बन्छ: Game price ($) × डलर रेट = तपाईंको लागत, त्यसमा तपाईंले राखेको नाफा % थपिन्छ र माथि राउन्ड हुन्छ। डलर रेटमा तपाईंको कार्डको लागत र आजको बजार रेटमध्ये जुन बढी छ त्यो लिइन्छ, ताकि घाटा नहोस्। तपाईंले गर्ने काम: नाफा % (जस्तै 10) छान्ने र Save थिच्ने मात्र। माथिको "How a price is made" मा हरेक प्याकेजको हिसाब चरणअनुसार देखिन्छ।

    Selling price is automatic: game price ($) × dollar rate = your cost, then your profit % is added and the result is rounded up. The dollar rate is the higher of your card cost and today’s market rate, so you never sell at a loss. All you choose is the profit % (e.g. 10) and tap Save. “How a price is made” shows the calculation step by step for any package.

    रिपोर्टReports

    Profit & loss statement मा महिना छान्नुहोस् (‹ ›)। Gross sales (सूची मूल्यमा बिक्री) − Discounts = Net revenue; Net revenue − COGS = Gross profit; Gross profit − Card fees = Net profit (खुद नाफा)। Memo मा नगद प्राप्त र उठाउन बाँकी रकम छ। Monthly P&L तालिकामा १२ महिनाको तुलना छ। Discounts given मा कुन ग्राहकलाई कति छुट दिनुभयो देखिन्छ।

    Pick a month in the profit & loss statement (‹ ›). Gross sales (at list price) − discounts = net revenue; net revenue − COGS = gross profit; gross profit − card fees = net profit. The memo shows cash received and receivables. The monthly P&L table compares 12 months, and Discounts given shows how much discount each customer received.

    ब्याकअप र रिस्टोरBackup & restore

    महिनामा एक पटक Download backup थिच्नुहोस् र फाइल सुरक्षित राख्नुहोस्। केही मेटियो भने Restore from a backup बाट फर्काउन सकिन्छ (अहिलेको डाटा फाइलकोले बदलिन्छ)। Excel मा हिसाब चाहिए Export CSV थिच्नुहोस्।

    Download a backup once a month and keep the file safe. If anything is deleted, restore it from that file (current data is replaced by the file). Use Export CSV for Excel or Google Sheets.

    पासवर्ड बदल्ने, reset link पठाउने र साइन आउट गर्ने ठाउँ। 👁 थिच्दा पासवर्ड देखिन्छ। ३० मिनेट केही नगरे सुरक्षाका लागि आफैं साइन आउट हुन्छ।

    Change your password, send a reset link or sign out. Tap 👁 to show the password. For security you are signed out after 30 minutes of inactivity.

    Start typing the name and pick it from the suggestions; phone and UID fill in automatically. You can also use ⋮ → Sell again on the Customers page.

    उधारो बिक्री कसरी राख्ने र पछि पैसा कसरी उठाउने?How do I record a credit sale and collect later?

    Payment method मा “Credit” छान्नुहोस् र Amount received मा अहिले पाएको रकम (वा 0) लेख्नुहोस्। पैसा आएपछि Dashboard को Accounts receivable मा Record payment थिचेर भुक्तानी माध्यम (Cash, eSewa…) छान्नुहोस्।

    Set the payment method to “Credit” and enter what you received now (or 0). When the customer pays, tap Record payment under Accounts receivable on the dashboard and choose how they paid (Cash, eSewa…).

    डायमन्ड पछि पठाउने भए?What if I deliver the diamonds later?

    बिक्री गर्दा Delivery status मा “Pending” छान्नुहोस्। Dashboard को Pending delivery मा देखिन्छ। पठाएपछि Delivered थिच्नुहोस्।

    Set Delivery status to “Pending” when recording the sale. It appears under Pending delivery on the dashboard; tap Delivered once sent.

    ग्राहकलाई निश्चित डायमन्ड चाहियो भने?A customer wants an exact number of diamonds

    New sale मा 🧮 Diamond calculator थिच्नुहोस्, कति डायमन्ड चाहियो लेख्नुहोस् र Find best थिच्नुहोस्। सबैभन्दा सस्तो प्याकेज मिलान देखिन्छ; Add to order थिच्दा सिधै अर्डरमा थपिन्छ। एउटै अर्डरमा जति प्याकेज पनि थप्न सकिन्छ।

    On New sale tap 🧮 Diamond calculator, enter the diamonds wanted and tap Find best. The cheapest mix of packages appears; Add to order puts it straight in the order. One order can hold any number of packages.

    उधारो रिमाइन्डर कसरी पठाउने?How do I send a payment reminder?

    Dashboard को Accounts receivable मा Remind 🔔 थिच्नुहोस्, वा ग्राहक प्रोफाइल/बिक्री विवरणमा “Remind to pay”। बाँकी सबै रकम सहितको WhatsApp सन्देश तयार हुन्छ। एक हप्ताभन्दा पुरानो उधारो Dashboard मा सूचनामा आउँछ।

    Tap Remind 🔔 under Accounts receivable on the dashboard, or “Remind to pay” in a customer profile or sale details. A WhatsApp message listing everything they owe is prepared. Credit older than a week shows as an alert on the dashboard.

    VIP र रिवार्ड कसरी काम गर्छ?How do VIP and rewards work?

    Pricing → Loyalty rewards मा सेट गर्नुहोस्। तोकिएको रकमभन्दा बढी किन्ने ग्राहक ⭐ VIP हुन्छन्। हरेक N औं खरिदमा New sale मा 🎁 रिवार्ड छुट देखिन्छ; Apply थिच्दा छुट लाग्छ।

    Set them in Pricing → Loyalty rewards. Customers who spend more than the set amount become ⭐ VIP. On every Nth purchase, New sale shows a 🎁 reward discount; tap Apply to use it.

    महिनाको हिसाब PDF/Excel मा कसरी निकाल्ने?How do I download the monthly statement?

    Reports → Profit & loss statement मा महिना छान्नुहोस्, तल PDF वा Excel थिच्नुहोस्। PDF मा प्रिन्ट विन्डो खुल्छ, त्यहाँ “Save as PDF” छान्नुहोस्। Excel मा P&L, Sales, Customers र Expenses छुट्टाछुट्टै sheet मा आउँछन्।

    Pick the month in Reports → Profit & loss statement and tap PDF or Excel below it. PDF opens the print window; choose “Save as PDF”. Excel has separate sheets for P&L, Sales, Customers and Expenses.

    कार्ड लोड गर्दा NPR कति काटियो कसरी हेर्ने?Where do I see how much NPR each load cost?

    Dollar card → Card ledger मा “Loads” छान्नुहोस्। हरेक लोडको USD, तिरेको NPR (शुल्कसहित) र Rate (प्रति डलर) देखिन्छ। माथि Total loaded र Load charges मा जम्मा छ।

    Dollar card → Card ledger → “Loads”. Each load shows USD, NPR paid (including charges) and the effective rate per dollar. Totals are in Total loaded and Load charges.

    अनुमानित नाफा र वास्तविक नाफा किन फरक?Why does actual profit differ from the estimate?

    बिक्री गर्दा देखिने COGS अनुमान हो। कार्ड लोड राखेपछि रिपोर्टहरूले कार्डको वास्तविक औसत लागत (WAC) प्रयोग गर्छन्, र कार्ड शुल्क Net profit बाट घटाइन्छ। त्यसैले Net profit नै तपाईंको वास्तविक नाफा हो।

    The COGS shown while selling is an estimate. Once card loads are recorded, reports use the card’s actual weighted average cost and deduct card fees from net profit, so net profit is your real profit.

    Gross profit कसरी हिसाब हुन्छ?How is gross profit calculated?

    Gross profit = Revenue − COGS। COGS = Game price ($) × त्यस दिनको Exchange rate + Card/bank charges। Credit बिक्रीमा पूरा मूल्य Revenue मा गनिन्छ (accrual); नउठेको भाग Accounts receivable मा देखिन्छ।

    Gross profit = revenue − COGS, where COGS = game price ($) × that day’s exchange rate + card/bank charges. Credit sales count at full price (accrual basis); the unpaid part appears in accounts receivable.

    Load गर्दा के लेख्ने? रेट कि जम्मा रकम?When loading, do I enter the rate or the total?

    सधैं जम्मा रकम लेख्नुहोस्: कति डलर आयो र त्यसका लागि जम्मा कति रुपैयाँ काटियो। रेट एपले आफैं निकाल्छ। रेट मिलेन भने रातो चेतावनी आउँछ। Opening balance मा पनि त्यस्तै: कार्डमा भएको डलर र तिनको जम्मा रुपैयाँ मूल्य।

    Always enter totals: how many dollars arrived and the total rupees taken from your account. The app works out the rate itself and shows a red warning if it looks wrong. The opening balance works the same way: dollars on the card and their total rupee value.

    Garena ले मूल्य बदल्यो भने?What if Garena changes a price?

    Price list → Packages मा प्याकेज थिच्नुहोस् → Game price ($) बदल्नुहोस् → Save package। पुराना कारोबारको हिसाब बदलिँदैन।

    Price list → Packages → tap the package → update the game price ($) → Save package. Past transactions are not affected.

    इन्टरनेट नहुँदा के हुन्छ?What happens without internet?

    बिक्री फोनमै सेभ हुन्छ र माथि “Waiting to sync” देखिन्छ। नेट आएपछि आफैं Firebase मा जान्छ। पेज बन्द नगर्नुहोस्।

    Sales are saved on the device and the top bar shows “Waiting to sync”. They upload to Firebase automatically when you are back online. Keep the page open.

    गल्तीले मेटियो भने?I deleted something by mistake

    मेटाउनासाथ तल “Undo” आउँछ, थिच्नुहोस्। धेरै मेटियो भने Backup & restore बाट फर्काउनुहोस्।

    Tap “Undo” on the message that appears right after deleting. For larger losses, restore from Backup & restore.

    “Permission denied” आयो भने?I see “Permission denied”

    Firebase को Firestore Rules ठीकसँग राखिएको छैन। Rules फेरि paste गरेर Publish गर्नुहोस्।

    Your Firestore rules are not set correctly. Paste the rules again in the Firebase console and publish.
